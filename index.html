Scrawny Summoner

Desktop Download Manager

Native desktop download manager and stream summoner built in Rust with GPUI. Handles direct files, BitTorrent, yt-dlp videos, and HLS/DASH streams with a companion Chrome extension.

Download Latest Release ↓ Source on GitHub ↗ Rust & GPUI

Core Capabilities

One native download manager for files, torrents, and web streams.

Direct

Fast Direct Downloads

Reliable HTTP/HTTPS file downloading with pause, resume, queue management, and clean progress tracking.

P2P

Built-in BitTorrent

Handle `.torrent` files and magnet links natively inside the same app without needing a separate torrent client.

Streams

yt-dlp & HLS/DASH

Summon videos and adaptive HLS/DASH streams directly from supported URLs with format and quality selection.

Extension

Chrome Extension + GPUI

Send downloads and detected media streams straight from Chrome into a fast, GPU-rendered Rust + GPUI desktop window.
